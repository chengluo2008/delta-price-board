数据说明 / 它是怎么工作的

变卖物指游戏《三角洲行动》里主要用来卖钱换哈夫币的收集品。数据站会给每件物品标品质颜色：蓝色、紫色、金色、红色。

价格取的是交易行当前最低挂单价格，随玩家挂单每分钟都在变。页面顶部的“数据时间”就是数据站最后一次更新价格的时间。

近 7 日区间是过去 7 天里的最低价和最高价，圆点表示当前价格在这个区间里的位置——越靠左下越便宜，越靠右上越贵。

这个看板由本机的 Python 小程序提供：它替浏览器去数据站取数（浏览器直接取会被“跨域”策略拦下），拿到后缓存 3 分钟，并顺手存一份到 data/snapshot.json，断网时还能看到上一次的数据。
