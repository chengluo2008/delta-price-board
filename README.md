# 三角洲行动 · 变卖物行情看板

**线上地址（手机也能看）：<https://chengluo2008.github.io/delta-price-board/>**

一个查《三角洲行动》收集品（变卖物）交易行价格的小网页：

- **蓝色品质**：全部变卖物，价格**从高到低**排好队
- **紫色品质**：最便宜的那件，单独放一张大卡片
- **金色 / 红色品质**：点页签切换查看（点开时才去取数）
- **两种用法**：电脑上双击 `start.bat` 是实时数据；线上版每天 9:10 / 21:10 自动更新

---

## 一、线上版怎么用

1. 手机或电脑浏览器打开：<https://chengluo2008.github.io/delta-price-board/>
2. **数据自动更新**：电脑上有一个 Windows 计划任务，每天 **9:10 和 21:10** 自动抓数据并发布（黑窗口不会弹出来）
3. 想立刻更新：双击 `更新数据.bat`，等它跑完，约 1 分钟后刷新网页

> 电脑关机 / 没登录时，那一次就跳过了；开机后如果错过了，Windows 会尽快补跑一次。

<details>
<summary>自动更新是怎么设的？想改时间或关掉怎么办？</summary>

计划任务名字叫 **三角洲行动物价自动更新**，它调用 `scripts/run_hidden.vbs`，静默运行 `更新数据.bat /quiet`。

- 看状态：开始菜单搜“任务计划程序”，左侧找到这个任务
- 改时间：右键任务 → 属性 → 触发器 → 编辑
- 关掉：右键任务 → 禁用（或删除）
- 命令行查看：`schtasks /Query /TN "三角洲行动物价自动更新"`

</details>

> 为什么不能 15 分钟全自动？全自动需要 GitHub 的 `workflow` 权限，而你这台电脑连不上 GitHub 网页（github.com 超时）。现在改用「电脑抓数据 → 通过 GitHub API 推送」，绕开了网页登录。哪天能登录 GitHub 网页了，2 分钟就能升级（见最后一节）。

## 二、本地版怎么用（实时数据，不用发布）

1. **双击**文件夹里的 `start.bat`
2. 会弹出一个**黑窗口**，等 1～2 秒，浏览器自动打开 `http://127.0.0.1:8848`
3. **看着的时候别关黑窗口**；不看就关掉它

> 黑窗口就是"发动机"，网页是"车壳"。发动机一关，车壳就打不开了。

## 三、页面怎么看

| 位置 | 是什么 |
| --- | --- |
| 顶部 4 个数字 | 蓝色变卖物件数、蓝色最高价、蓝色最低价、紫色最低价 |
| 品质页签 | 蓝色 / 紫色 / 金色 / 红色，点一下切换排行榜 |

## 四、常见问题

**线上网址打不开 / 很慢？**
GitHub Pages 在国内网络时快时慢，多刷新几次，或者换个网络（比如手机流量）试试。

**`更新数据.bat` 提示"抓取失败"？**
数据站或你的网络暂时不通，没有发布任何东西，旧数据还在。过一会儿再双击一次。

**`更新数据.bat` 提示"发布失败"？**
连不上 GitHub 的接口。数据已经存在本地了，等网络好点再双击一次。

**计划任务怎么知道有没有跑？**
`schtasks /Query /TN "三角洲行动物价自动更新" /V /FO LIST` 能看到"上次运行时间"和"上次结果"（0 就是成功）。也可以直接看线上网页顶部的「数据时间」。

**双击后一闪就没了？**
先打开一次 DeepSeek Harness 再双击（脚本要用它自带的 Python）。

**提示端口被占用？**
本地版会自动换成 8849、8850…… 具体网址看黑窗口里打印的那行。

**杀毒软件弹窗警告？**
这是本机跑的普通 Python 小脚本，不会上传你的任何私人信息，选择「允许」即可。

## 五、文件都是干嘛的

```
sanjiaozhou/
├─ start.bat            ← 本地版：双击启动实时网页
├─ 更新数据.bat          ← 线上版：双击抓数据并发布
├─ server.py            ← 本地小服务器：取数据 + 发网页
├─ docs/                ← 要发布到网上的网站文件（GitHub Pages 只认这个目录）
│  ├─ index.html        ← 页面骨架
│  ├─ styles.css        ← 外观样式
│  ├─ app.js            ← 交互逻辑
│  └─ data/*.json       ← 价格数据（由脚本生成）
├─ scripts/
│  ├─ fetch_data.py     ← 抓取四种品质 → 写成 JSON
│  ├─ publish.py        ← 把改动通过 GitHub API 推送（替代 git push）
│  └─ run_hidden.vbs    ← 让计划任务静默运行，不弹黑窗口
├─ data/snapshot.json   ← 本地缓存快照（断网兜底，不进仓库）
├─ .github/workflows/   ← 全自动更新的配置（需要 workflow 权限才能启用）
└─ README.md
```

## 六、想改点什么

| 想改 | 改哪里 | 怎么改 |
| --- | --- | --- |
| 主色（橙色） | `docs/styles.css` 顶部 `--accent` | 换颜色代码，比如 `#00d0ff` |

改完 `docs/` 里的文件后，**双击 `更新数据.bat`** 就会把改动一起发布上去（它会自动只上传有变化的文件）。

## 七、数据从哪来

- 价格来自 [DerGame 小Der数据报](https://dergame.cn/?type=armory) 的公开接口，它抓的是游戏内交易行真实挂单。
- 这里的「变卖物」对应游戏里的**收集品**分类。
- 价格随时在变，本页面仅供学习、娱乐参考，买卖请以游戏内实际交易行为准。

## 八、它是怎么工作的

**本地版：** 浏览器有「跨域」限制，不能直接去别的网站拿数据，所以 `server.py` 当跑腿的，取回来再交给网页。数据在内存里缓存 3 分钟，并往 `data/snapshot.json` 存一份兜底。

**线上版：** GitHub Pages 只能放静态文件，没有跑腿的程序。所以：

1. `fetch_data.py` 在你电脑上抓数据，写成 `docs/data/*.json`；
2. `publish.py` 通过 `api.github.com` 把这些文件提交到仓库（这台电脑连不上 `github.com`，但 API 是通的）；
3. GitHub Pages 发现仓库有更新，自动重新构建，网址不变。

**定时：** Windows 计划任务每天 9:10、21:10 调用 `run_hidden.vbs`（隐藏窗口），它再执行 `更新数据.bat /quiet`，也就是上面 1、2 两步。

**以后想升级成 15 分钟全自动**（电脑关机也更新）：
需要一个有 `workflow` 权限的 GitHub 授权。拿到后把 `.github/workflows/update-prices.yml` 加进仓库，再把仓库 Settings → Pages 的 Source 改成「GitHub Actions」即可。到时候跟我说一声，我带你弄。
