# 三角洲行动 · 变卖物行情看板

一个跑在你电脑上的小网页：每天自动更新《三角洲行动》收集品（变卖物）的交易行价格。

- **蓝色品质**：全部变卖物，价格**从高到低**排好队
- **紫色品质**：每天最便宜的那件，单独放一张大卡片
- **金色 / 红色品质**：点页签就能切换查看（点开时才去取数，不拖慢首屏）
- 每 120 秒自动刷新，顶上有「数据时间」，能看出数据新不新

---

## 一、怎么打开（就 3 步）

1. **双击**文件夹里的 `start.bat`
2. 会弹出一个**黑窗口**，等 1～2 秒，浏览器会自动打开网页
   （如果没自动打开，自己在浏览器地址栏输入 `http://127.0.0.1:8848` 回车）
3. **看着的时候别关黑窗口**；不想看了，直接关掉黑窗口就停止服务了

> 黑窗口就是"发动机"，网页是"车壳"。发动机一关，车壳就打不开了。

## 二、页面怎么看

| 位置 | 是什么 |
| --- | --- |
| 顶部 4 个数字 | 蓝色变卖物件数、蓝色最高价、蓝色最低价、紫色最低价 |
| 品质页签 | 蓝色 / 紫色 / 金色 / 红色，点一下切换排行榜 |
| 左边长列表 | 当前品质的排行榜，价格从高到低；可以上下滚动，也可以搜索名字 |
| 右边大卡片 | 紫色品质里当前最便宜的那件，附 7 日最低 / 最高 / 现在比低点贵多少 |
| 每行右侧的小横条 | 当前价在"近 7 日区间"里的位置，越靠左越便宜 |
| 顶部「数据时间」 | 数据站最后一次更新价格的时间（不是你看页面的时间） |

颜色小贴士：蓝点 = 蓝色、紫点 = 紫色、金点 = 金色、红点 = 红色；价格单位都是**哈夫币**。

## 三、常见问题

**双击后一闪就没了？**
多半是没找到 Python。先打开一次 DeepSeek Harness 再双击；还是不行就装一个 Python（<https://www.python.org/downloads/>，安装时记得勾选 `Add Python to PATH`）。

**提示端口被占用？**
不用管，程序会自动换成 8849、8850…… 具体网址看黑窗口里打印的那一行。

**页面显示「缓存数据」？**
说明数据站这会儿连不上，程序把上一次成功拿到的数据先展示给你了。过几分钟点右上角「刷新」试试。

**杀毒软件弹窗警告？**
这是本机跑的普通 Python 小脚本，没有联网上传任何东西，选择「允许」即可。

**关掉黑窗口后网页打不开了？**
正常的。重新双击 `start.bat` 就行。

## 四、文件都是干嘛的

```
sanjiaozhou/
├─ start.bat            ← 双击这个启动
├─ server.py            ← 本地小服务器：取数据 + 发网页
├─ web/
│  ├─ index.html        ← 页面骨架
│  ├─ styles.css        ← 外观样式（颜色、排版）
│  └─ app.js            ← 交互逻辑（取数、排序、搜索、倒计时）
├─ data/
│  └─ snapshot.json     ← 自动生成的数据快照（断网时兜底用）
├─ .preview/            ← 截图，可以删
└─ README.md            ← 你正在看的这份说明
```

## 五、想改点什么

| 想改 | 改哪里 | 怎么改 |
| --- | --- | --- |
| 端口 | `server.py` 顶部 `DEFAULT_PORT` | 改成 9000 之类，保存后重启 |
| 自动刷新频率 | `web/app.js` 顶部 `REFRESH_SECONDS` | 单位是秒，现在是 120 |
| 主色（橙色） | `web/styles.css` 顶部 `--accent` | 换成别的颜色代码，比如 `#00d0ff` |
| 默认打开哪个品质 | 不用改代码 | 网址后面加 `?grade=gold`（金）、`?grade=red`（红）等 |
| 再加一种品质 | `server.py` 的 `GRADE_CN` | 目前游戏里就这 4 种颜色，一般不用改 |

改完保存，刷新浏览器（`Ctrl + F5`）就能看到效果。

## 六、数据从哪来

- 价格来自 [DerGame 小Der数据报](https://dergame.cn/?type=armory) 的公开接口，它抓的是游戏内交易行真实成交价。
- 这里的「变卖物」对应游戏里的**收集品**分类。
- 价格随时在变，本页面仅供学习、娱乐参考，买卖请以游戏内实际交易行为准。

## 七、它是怎么工作的（大白话版）

浏览器有个安全规定叫「跨域」：A 网站的网页不能随便去 B 网站拿数据。
所以让本机的 `server.py` 当跑腿的——它去数据站把价格拿回来，再交给网页。

为了不反复打扰数据站，每个品质的数据会单独在内存里**缓存 3 分钟**；金色、红色是你点开页签时才去取的，首屏只拉蓝色和紫色。
每次成功后还会往 `data/snapshot.json` 存一份，万一网络抽风，页面就显示上一次的数据并标上「缓存数据」。
